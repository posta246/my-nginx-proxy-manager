# Dependency update logs

This folder contains one Markdown log per day describing the automated dependency
and CVE update sweep performed by the
[`Daily Dependency Update`](../../.github/workflows/daily-dependency-update.yml)
GitHub Actions workflow.

Each day the workflow commits the sweep to a dated branch
(`automated/dependency-updates-YYYY-MM-DD`), opens a pull request, **merges it into
`develop`**, and then creates a GitHub **release** named and tagged `YYYY.MM.DD`
whose notes are the contents of that day's log file below.

## Naming convention

Each log file is named after the (UTC) day it was produced, using the pattern:

```
YYYY-MM-DD.md
```

For example, `2026-09-16.md`.

If the workflow runs more than once on the same day (for example a scheduled run
plus a manual `workflow_dispatch`), each run appends a new timestamped section to
that day's file rather than overwriting it.

## What each log contains

For every JavaScript sub-project (`backend`, `frontend`, `docs`, `test`):

- the `yarn audit` vulnerability summary **before** the update (CVE counts by severity),
- the list of outdated packages,
- the result of `yarn upgrade` (upgrades within the declared semver ranges),
- the `yarn audit` summary **after** the update,
- whether the lockfile changed, with a `git diff --numstat` summary.

The logs are generated by [`scripts/ci/daily-dependency-update.sh`](../../scripts/ci/daily-dependency-update.sh),
which can also be run locally:

```bash
# Full run (updates lockfiles):
./scripts/ci/daily-dependency-update.sh

# Audit-only dry run (no upgrades):
NPM_UPDATE_SKIP_UPGRADE=true ./scripts/ci/daily-dependency-update.sh
```
